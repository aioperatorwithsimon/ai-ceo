# CEO ledger — format

One file per month (`YYYY-MM.md`), append-only. If something was wrong, add a correction entry
instead of editing the old one.

```markdown
## 2026-10-14 (Wed) — CEO RUN

**Mode:** post + research. Day-2 numbers are in and the vote closed.

| Time | Action | Why | Result |
|---|---|---|---|
| 10:06 | Read followers on all four channels | The goal metric | IG 360 · TT 81 · FB 16 · YT 9 |
| 10:12 | Read every comment on yesterday's post | The vote lives in comments | 7 votes: NEW 5, KEEP 2 |
| 10:20 | Sent 2 research agents: logo trends in the niche · how competitors announce a rebrand | Public decision, so research first | Findings saved in Research.md |
| 11:05 | Built + published Day 2 ("You voted. Here's the new logo.") | Honouring the vote, in public | 4 URLs |

**Decisions:** <changes to the bet, the brand or the machine, with the evidence>
**Asked the owner:** <what, or "nothing">
```

*(Every number above is illustrative. A real ledger only holds measured ones.)*
